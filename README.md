# sanctuarysound.studio

This is the official website for https://sanctuarysound.studio, a boutique project music studio located near Daytona Beach, Florida.

Sanctuary focuses on keeping the vibe and helping the art of making music thrive.

We are a hybrid studio running Protools Ultimate as our core DAW with quality Solid State Logic super analog audio interface. We run analog outboard gear but mix "in the box".

We focus, mostly, on mixing and mastering, but can track and capture your art the way it deserves.
